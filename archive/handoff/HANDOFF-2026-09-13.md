## 一、🔴 最要紧的一条：这个项目的验收标准

**「跑一遍测试全绿」在 Caelum 不是证据。**

2026-09-13 一天之内，**五次「我以为验过了、其实什么都没验」。靠全绿抓到的是 0 次。**
全部靠故意改坏、或者数字看着不对才发现。

已经立成规矩（`CAELUM-MAP.md` 第三·五节 + `CLAUDE.md` 必读块）：

> **任何一处改动，交付之前必须把它故意改坏一次，确认对应的检查会红。**
> 红不了的检查不算检查。

**做统筹验收时，这一条就是验收标准本身。**
派给 Zcode / codex 的任务，验收时要问的不是"测试过了吗"，而是：

1. **你把它改坏过吗？改坏之后哪几条红了？** ← 没有这个就是没验
2. 检查覆盖到**被改的那个东西**了吗？（不是它旁边那个）
3. 这条检查**能挡什么、不能挡什么**？说不清就是噪音

### 五种已知的假验证形状（照着这个清单查）

| 形状 | 长什么样 |
|---|---|
| **空集不是通过** | 找到 0 条，却打印「全部通过」。要加「少于 N 条不下结论」 |
| **判据在路上变形** | 匹配中文/文本，而编码转换让它永不成立。判据要挑**退出码 / HTTP 码 / 文件在不在** |
| **依赖是个假壳** | 本机 `python3` 是微软商店占位壳：存在、`command -v` 找得到、退出码 0、**零输出**。判据只能是"让它真算一次看结果" |
| **测的不是那件事** | 把锁换成空壳，并发压测照样全绿（真正挡住崩溃的是 `list()` 拷贝） |
| **检查没覆盖被改的东西** | 只 `import utils`，漏掉被改模块里的运行时 `NameError`。`py_compile` 抓不到运行时错误 |

外加两条：**`|| true` 不许用在判据上**；**空断言**（断言一个根本不存在的字段被清掉了）。

- 测局域网要 `curl --noproxy '*'`（她的 Clash 会劫持）

### 部署

```
powershell -NoProfile -File scripts/deploy.ps1 <服务> [commit]
```
服务：`nox-core` / `bridge` / `touch-server` / `co-watching` / `touch-mcp`。
**前提是先 commit。** 失败自动回滚。现在退出码是可信的（今天修的）。

**Ombre-Brain 不走这套** —— 它是 VPS 上的独立仓库，改动要写成
`scratch/apply-*.py` 脚本执行。写这类脚本的三条教训（今天全踩过）：

1. **锚点不要写死缩进** —— 用正则捕获缩进
2. **读写要保留换行风格** —— `read_text`/`write_text` 会把 CRLF 转成 LF，
   整个文件变成 diff，**没法审 = 没法验**
3. **插 import 只插顶层** —— `replace("from utils import", ...)` 会命中
   函数体内的局部 import，造成运行时 `NameError`，而 `py_compile` 抓不到

改线上 systemd / 重启服务 / 部署，**每一次都要她明确说**。

## 五、几条容易被误解的事实（省得重新踩）

- **`FastMCP(host=...)` 不是监听地址**，是 DNS-rebinding 白名单。
  改窄会让网页连接器全变 421。真正的监听在文件末尾的 `uvicorn.run`
- **Caddy 会重排块内指令**（`respond` 排在 `reverse_proxy` 前面），
  要限制路径得包一层 `route {}`
- **`busy_timeout` 不用管** —— Python `sqlite3.connect()` 默认 `timeout=5.0`
  就是 5000。用 `sqlite3` 命令行读到的 0 是**命令行自己那条连接**
- **`list(d.values())` 在 GIL 下原子**，`[v for v in d.values()]` 会抛
  `dictionary changed size during iteration`。挡住崩溃的是前者，不是锁
- **测试会话用 `test-` 前缀**，用完自清理。
  今天清掉了 37 个攒了十天的陈年测试会话
