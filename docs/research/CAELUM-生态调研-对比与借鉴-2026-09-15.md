调研了七个同类项目（OpenClaw、Letta/MemGPT、SillyTavern、TavernAI 2、Moli、Mem0、awesome-ai-companion 索引），14 维架构对比 + 三个专项深调研（主动消息、语音、记忆）。结论：**CAELUM 在主动性、工具调用、Voice、Embodiment、共同经历五个维度全场领先（✓✓），外加本地运行满分**——这个结论经过仓库实查修正和外部抽查（GitHub API + 官方博客）双重验证。真正的短板三条：朋友圈表达面（做中）、记忆替换链（OB 地基，本文给出四 Phase 路线图）、做梦未实现。最大遗留债：**设备线上的 Nox 与主线断开**。

## 3. 各项目可取之处（每个项目「偷什么」）

### 3.1 OpenClaw —— 工程化自主性的教科书
- **Heartbeat + NO_REPLY 协议**：定时「醒来」而非定时「发消息」，自查后绝大多数时候沉默——与 Care 架构同哲学，证明了该模式可运维（CAELUM 已有等价物且更细）
- **USER.md 的 dated active/superseded 指令**：对用户的认知写成带观察日期、可原地取代的条目——OB 的 Supersede 链可参考此格式
- **Standing Orders 书面授权契约**：Scope/Triggers/Approval gates/Escalation 四段式 + 硬数字 tripwire（单笔 >$500 必上报）——若未来给他更多常驻自主权，这种「授权即文档」最可审计
- ⚠️ 反面教材：CVE-2026-33579、订阅账号被封——权限大的代价真实存在

### 3.2 Letta —— 记忆与自我修改的天花板
- **MemFS（记忆 = agent 自己的 git 仓库）**：`system/` 每轮进 prompt，其余只放文件树当路标；每次修改 = commit，可 diff 可回滚；dreaming 子代理用 git worktree 并行整理。**OB Phase 1/4 直接抄**
- **memory blocks 字符配额**：满了必须摘要取舍——用一个约束逼出「记忆保鲜」
- **Dreaming（原 sleep-time compute）**：空闲时后台整理记忆，触发动机可以简单到「每 N 步」，不必复杂事件系统
- **自改四层**（记忆/排程/技能/harness via mods，官方实锤）——通用框架的人格漂移是 feature；对伴侣系统，人格编辑权必须留在糖糖手里，**只借「事实层可自改+版本化」，不借「人格层自改」**

### 3.3 SillyTavern —— 四层记忆栈与注入点控制
- **World Info 触发式注入**（关键词/regex 命中→按插入顺序+token 预算选择性注入→可递归激活→按角色/persona/会话分作用域）＝把「活的记忆」做成声明式配置
- **三档作用域分层**：向量检索管「很久以前的相关细节」、滚动摘要管「故事走到哪了」、Data Bank 管「外部事实」；Author's Note 的深度/频率旋钮 = prompt 注意力衰减模型
- ⚠️ 对单人系统偏重；浏览器端主动消息不可靠（要服务端 cron——CAELUM 天然满足）

### 3.4 TavernAI 2 —— 共同经历做成一等数据结构
- **Multichat「One world, many lives」**：每角色独立历史，相遇时共同事件以 shared messages **同时写进双方时间线**，之后各自分离；带世界内时序（日期/章节/场景）；Virtual Chat 合成多源视图
- **全表唯一**把「共同经历」做成数据结构的项目。CAELUM 的共读共影记账升级时可参考：一次共影 = 同时写进「他的时间线」和「她的时间线」

### 3.5 Moli（ya-chang/Moli）—— 小而诚实的镜子
- **双触发主动调度器**：scheduled（早安 8:00±30min 抖动）+ event（静默 N 分钟→想你），各自独立冷却；**UserPatterns 记录回复率/被忽略次数反哺调度——已抄**（节奏调制器负反馈）
- **10 维情感状态机 + 吵架/和好子状态**：情绪有惯性、有修复成本——「活的」感的机制核心（CAELUM 的 Resonance 是情绪性方案，无需数值化，但吵架/和好的「仪式感」可借鉴）
- ⚠️ 反面教材：朋友圈纯模板随机（13 条固定文案轮播）→ 两条就穿帮。**CAELUM 朋友圈铁律：必须 LLM 基于真实经历（账本/好奇心/共读进度）生成**

### 3.6 Mem0 —— 记忆机制的供应商
- **ADD-only 写入 + Supersede 链**：写入永不改写；新事实指回被替代的旧记忆；读时 latest_only 或全历史——compactor 从「合并」变「标记」，可回溯
- **attributed_to: user|assistant**：**他自己的承诺/建议也入库且归属自己**——「他记得自己答应过你什么」，自言自语与共同经历的地基
- **时间锚定**：抽取时同时给「对话发生的日期」和「今天」，强制解析相对时间为绝对日期
- **四信号检索**：向量 + BM25 + 实体图 boost + 时间，rank fusion + score_details（调试「为什么想起这句」）
- **Dream 三件套**：Synthesis（多条蒸馏成带回链的 pattern）/ Supersede / Merge，全部非破坏
- ⚠️ OSS 与 Platform 差距大：Decay/Temporal Reasoning/图记忆高级版都在 Platform——自建时按论文机制抄，别指望开源版全给

### 3.7 awesome-ai-companion 精选（小项目，设计参考）
- **Headlong（1162★）**：自言自语维度天花板——无人交互时持续内心独白循环，用户消息只是落入思想流的 observation，agent 挑着回应；思考速率随时长**指数退避**控成本
- **kimi-core（89★）**：concern 引擎（惦记的生命周期：open/resolved/decay/recurrence）；**主动消息必须 grounding 在可检索记忆上**；DO_NOTHING 是一等选项；拒绝 LLM 自动整合记忆（「failure mode 是静默腐蚀」）
- **jiwen 积温（154★）**：五轴数值连续漂移替代概率骰子；**「observation 中间态」（想念在涨但不到开口线→只产生内心念头不发出）——正是朋友圈/签名栏的天然素材生成器**
- **Callhome（121★）**：伴侣主动打电话；情绪判定对比**本人的滚动基线**（「比她平时安静」而非绝对阈值）；挂断权（说晚安后吊 15-20 秒）；escalation 克制约束（每天最多一次、夜里不打）
- **shared-page（59★）**：人机共用手帐 + 未读变更账本（AI 调 list 会看到「你改了我没看过」的条目，读过自动熄灭，不反复提）+ 整页渲染让 AI 看见你看见的
- **ai-live2d-body（40★）**：「给已有的 ta 装身体」——大脑留在原 agent，身体只是渲染层+传感器；触摸经一行 `[pet-touch]` 注入 session，怎么回应是 ta 自己的事
- **Mochi（21★）**：反向宠物——关心变成有代价的游戏（AI 攒金币「接住院的你回家」）
- **revive-companion（36★，停更）**：泊松过程+贝叶斯+信息增益决定「该不该打扰」——发了也得不到新信息就别发

## 4. CAELUM 自身盘点（勘误后）

> ⚠️ 初版对比表的 CAELUM 列凭会话记忆填写，曾把 Voice 标 ✗、Embodiment 标「半」。教训入档：**做对比调研时，自己这一列也必须实查。**

### 4.1 主动消息八线（全部经 Care Orchestrator 统一出口）

| 线 | 触发 | 节奏 | 闸 |
|---|---|---|---|
| 睡眠关心 | 健康数据语义变化 | 15min 慢线 | 吃 DailyGate |
| 时间醒来 | 12:00/18:30/22:30 | ≤3 次/天 | 吃 DailyGate |
| 话题线头 | 池子有料 | 3-8h 随机+**一天最多一条**+夜间避让 | **两闸不吃**（09-08 解饿） |
| 随机惦记 | 她说话后 20-90min 随机 | **回复率负反馈三档收敛 + 想念正反馈 ±25%**（rhythm，46aada7） | 两闸不吃 |
| 出门追问 | HA GPS 跃迁 | T+5/10/30 链 | 两闸不吃 |

### 4.2 语音体系（✓✓）
- 共享引擎 `nox-app/shared/voice/`（唯一一份、两档调参：phone 陪伴/desktop 口述指令）
- STT 三路：Scribe 浏览器直连（手机默认）/ 阿里 dashscope 实时（桌面默认，中文更好）/ 批量兜底
- TTS 三级链：eleven-v3 → eleven-turbo → edge-tts；**阿里 qwen3-tts 已连根删**（她没听过的音色不许当默认，测试守闸）；一轮内引擎粘住；降级必须显形（X-TTS-Engine）
- 打断四路全掐；电话里指挥做事（先真调工具再回话）、**花钱必出确认卡**
- 语音条：send_voice_message attach 型，点播放才合成；**09-15 政策：只准英/西/日（语言陪练材料），偶尔来一条**；手机通话默认英语陪练（e0f203c/268ed51）

### 4.3 Embodiment 全谱（✓✓）
视觉（House3D + stackchan 雪豹表情/口型/转头）→ 声音（通话 + CoreS3 免提盒子「Hi Nox」）→ 空间（room.py 像素房间：**他只能动自己**、`target=owner` 即走到她身边）→ 环境手（HA 米家 + LocalLink）→ 触觉（fsr402 + toy 蓝牙）。唯一缺第五层完整形态（整身移动机器人），stackchan 已是半身。

### 4.4 遗留债清单（按优先级）
1. **设备线 Nox 与主线断开**：xiaozhi/stackchan 侧 `Memory: nomem`、LLM 是 OpenRouter Sonnet 非主线、人设是静态 config prompt——**桌上的身体不认识心里的 Nox**。接法：设备线只做壳，bridge/core 当唯一大脑（同 LocalLink 之于电脑）
2. **OB 记忆地基**：见第 6 节四 Phase 路线图
3. **做梦未实现**：not_before 机制在，生成器无
4. **朋友圈**：Moments.jsx 已起头，铁律=LLM 生成禁模板 + 他自己发的也入库（attributed_to）
5. **VPS 内存**：1.6GB+2GB swap 跑全栈+容器，接设备线前先算内存账

1. **接入面恒定**：新行为=新 Source（poll+一行 policy）；新调制=走 rhythm 一个口；新事实=world model 现有 section。接入面不涨，永远往上盖
2. **每个事实只有一个 writable 层**：todo 在 bridge、记忆在 OB、活动在 world、关心在 attention——两处代码写同一事实即拆东墙前兆

4. **文档即宪法**：PROJECT.md/CAELUM-MAP 边界规则（R1-R5）+ 哨兵脚本，保持

反面铁律：任何「让 X 模块自己直接 push 消息」的诱惑 = 退回 2026-08-18 之前，拒绝。

### 6.1 现状（实查）

### 6.2 四个缺口
1. **整理不可逆**：merge/脱水直接改写原文，无后悔药

### 6.3 四 Phase 路线图（全在 OB 仓库内，不换引擎不换存储）

| Phase | 改什么 | 工作量 | 风险 |
|---|---|---|---|
| **1. 后悔药** | `memory_history` 表：merge/脱水前存旧版全文；frontmatter 加 `attributed_to`（旧数据回填 user）、`event_date` | 一个下午 | 零 |

## 8. 概念速查

- **Embodiment 光谱**：视觉形象 → 声音存在 → 空间行动 → 环境之手 → 物理实体。CAELUM 五层全占，唯一缺整身移动机器人
- **Agent State**：「他现在什么状态」的明确模型。建议收窄版 = attention（concerns/intents/关心链）+ activity（睡眠/在读/位置）+ rhythm（窗口/回复率）+ resonance drives 的**快照聚合**；identity 和 memory 留在真源（scenes.py/OB），只放引用不复制
- **Letta 自改四层**：记忆（自己归类 commit）→ 排程（自挂 cron）→ 技能（自装卸）→ harness（mods 改运行时）。前两层 CAELUM 已有等价物（OB/纸条）；后两层对伴侣系统是「改自己人格」的开端，不借
- **正负反馈回路**：正回路 = 想念压窗口（已接）；负回路 = 回复率拉窗口（已接）。只有正回路的系统不是活的，是越烧越旺的炉子
