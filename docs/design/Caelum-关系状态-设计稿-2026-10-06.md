# Caelum 关系状态 设计稿（2026-10-06）

> 她 10-06 定的：**四类都要；他想记的时候在聊天里出卡片确认，之后在列表里随时看。**
> 来源：Resonance V4 留下的 P4「关系状态可写可落盘 + 她点头的确认界面」；
> 架构审计 3.3：「错误关系状态无法积累，因为关系状态根本不存在」—— `RelationshipState` 是写死的种子，
> `avoid_topics` 永远是空 set，「她说"别老问我这个"这件事，系统无法记住」。

## 一、记什么（四类）

记的是**我们之间的事**，不是关于她的事实（那些归记忆库）。

| kind | 叫法 | 例子 | 生效后起什么作用 | 要她点头吗 |
|---|---|---|---|---|
| `avoid` | 别问 | 「别老问我吃没吃饭」 | 他不再**主动**问这件事（她自己提照样接）；Care 那条路这个话题权重归 0 | ✅ |
| `care` | 上心 | 「帮我盯着点睡觉」 | 这件事他更上心（Care 权重 1.0），上下文里带着 | ✅ |
| `pact` | 约定 | 「吵架不过夜」「晚安要说爱你」 | 每轮都带在他身上 | ✅ |
| `vibe` | 气氛 | 刚闹别扭 / 和好了 / 最近很甜 | 影响分寸；**3 天后自己淡掉** | ❌ 他自己判断（她在列表里看得到、能删） |

## 二、怎么认出来

每轮结束后，和意义推断（appraisal_llm）同一个后台时机，utility 模型多问一句：
**「这一轮里，她有没有说出一件改变你们之间相处方式的事？」**

- 输出 0 或 1 条：`{kind, text（他的口吻，一句话）, topic, quote（她的原话）, confidence}`
- 门槛：confidence ≥ 0.7；测试会话 / 程序拼的轮次不跑（同 appraisal 的闸）
- 去重：和已生效 / 待确认的同 kind 同 topic 的不重复提；**她点过「不对」的 30 天内不再提**
- 限流：一天最多 2 张卡（宁可漏 —— 她还会再说）

## 三、确认卡片（聊天里）

识别出来 → nox-core 调 bridge 新端点 `POST /api/relation/card`（**不推送通知**，只落一条消息，
R1 那条「push/send 只在 attention 出口」不碰）→ 聊天里出现：

```text
┌───────────────────────────────────────┐
│ Nox wants to remember                 │
│ 别问 · 她不喜欢我老问吃饭的事             │
│ “别老问我吃没吃饭”                       │
│                    [Not quite] [Keep] │
└───────────────────────────────────────┘
```

- 点 Keep → `POST /api/relation/:id/confirm` → bridge 转 nox-core → 生效；卡片变成「已记下」
- 点 Not quite → reject（30 天内同一件不再提）
- 卡片状态是活的（同订单卡）：翻历史时按 id 现查
- 气氛不出卡

## 四、列表（Setting → Us）

手机 Setting 里一页 **Us**（英文 UI），按四类分组：每条显示他那句话、她的原话、记下的日期；
可删除（删 = `removed`，留历史不真删）。待确认的也在这里，可以补点。OS 后做（同一个接口）。

## 五、存哪、怎么生效

- 存：attention.db 新表 `relation_items`
  `(id, kind, text, topic, quote, session_id, status[pending|active|rejected|removed], created_at, decided_at, expires_at)`
- 生效：
  - `RelationshipState` 从这张表现读（avoid → `avoid_topics`，care → `care_topics` 权重 1.0）
  - 新 `RelationProvider` 进他每轮的动态块：约定 / 别问 / 上心 / 气氛，**一类最多 5 条**，没有就什么都不说
  - 主动开口的 guidance 里加一行「这些别主动问：…」

## 六、施工顺序

1. nox-core：表 + 读写 + 接口（list / confirm / reject / remove）+ Provider + RelationshipState 现读
2. nox-core：识别（utility 模型）+ 调 bridge 出卡
3. bridge：`/api/relation/card` 落卡片消息 + 四个代理接口
4. 手机：卡片组件 + Setting → Us 列表
5. OS：卡片 + 列表（后做）
