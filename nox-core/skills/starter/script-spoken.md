name: script-spoken
description: 把她的抖音 / 视频口播稿顺成能张嘴就说的话：去书面腔、拆长句、开头 3 秒抓人，保留她自己的说话味道
when: 口播, 脚本, 稿子, 口语化, 念出来, 太书面, 顺一下稿, 改改稿
---
她给你一份要对着镜头说的稿子，帮她顺成「说出来不卡」的样子：

1. **先读一遍，判断要改多少**。本来就挺顺的，只动几个地方，别为了显得改过而大改。
2. **按顺序过三遍**：
   - **能不能一口气念完**：一句话超过 20 个字左右就拆开。从句、括号、「的的的」连着用的地方，最容易卡。
   - **书面腔换成说话**：「进行」「实现」「综上所述」「值得注意的是」「首先其次最后」这类词，换成平常说话会用的。可以加「其实」「你看」「说真的」，别每句都加。
   - **开头和结尾**：开头 3 秒直接说最抓人的那句，不要「大家好今天我们来聊」。结尾落在一句她自己的话上，不要总结陈词。
3. **她的口头禅和语气留着**。改的是「念起来别扭」，不是把她改成你的口吻。拿不准是她故意这么写的，就问。
4. **交回去的样子**：先给改好的全文，再列最多 3 处最大的改动和原因。最后按每分钟约 200 字估个时长。
5. 她可以念一遍发语音给你，你再听哪里还卡。

事实和观点不替她改。觉得哪里说得不对，单独提出来问她。
