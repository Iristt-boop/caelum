Memory 星空页二稿：记忆星直接画进 Galaxy 的 shader

她看了第一版（DOM 星叠在 shader 银河上）说：星光要和星空里的星是
同一种样式、只差一点颜色，而且不能固定死、要跟着星空流动，再加拖拽。

- 废弃 DOM 星方案，改为把每段记忆作为 uniform 数据喂进 Galaxy 组件，
  在 fragment 里用和背景星同一支笔刷、同一片旋转后的 uv 画出来 ——
  样式和流向天生一致。数据走 100×3 的 RGBA 数据纹理（字节编码：
  坐标16位、颜色、亮度/星芒/相位），不用 uniform 数组 —— 数组的动态
  索引在部分 ANGLE 实现上会误编译成读零，纹理采样哪都稳。
- ⚠️ ogl 数据纹理的 image 必须直接是 TypedArray（宽高放顶层选项），
  传 { data, width, height } 对象会走进 DOM 图片分支、每帧抛异常黑屏；
  ⚠️ flipY 默认 true 会把三行数据上下翻转，采样全串行（表现为星星全挤
  到右边缘拉成竖条）—— 数据纹理必须显式 flipY: false。
- DOM 只剩隐形点击热区：rAF 里用和 shader 相同的角 A 把锚点映射回
  屏幕像素（shader 特征转 R(+A)，DOM 层取 -A 补 CSS 正角顺时针），
  点热区开详情、拖天空旋转、Esc/点空处合上。
- 布局改日期排名定半径：真实日期跨度挤在近两个月，按年龄排会糊成
  一团；按新旧排名均匀摊开，核心仍是最新，边缘是旧事。
- 鼠标无排斥力、无视差（热区映射要逐像素对齐），拖拽即旋转。
