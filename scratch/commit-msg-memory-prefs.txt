星空设置面板：数量和色盘可调，偏好存 localStorage

她看完密密麻麻的天说：能不能自定义星星的密度和颜色。

- Memory 页头加「✦ 星空」按钮 → 深色玻璃面板（左上角，滑杆/点选都不会
  顺手把天拖转——面板上 stopPropagation 了）
- 星星数量 20-100：超过部分优先留重要 + 新近的，其余沉进背景；
  排名半径按过滤后的集合重算，星星少了自动摊得更开
- 四套色盘：暖金（默认）/ 月白 / 玫瑰 / 极光——都是和背景冷白
  同一系里的深浅变化，不是纯饱和色；钉住的永远取盘里最深那档
- 偏好存 localStorage（caelum-memory-galaxy），下次进来还是她的天
