# Caelum OS 桌面端 —— 设计稿需求文档（可爱版 v2）

> 给 Claude Design 的完整 prompt。基于初稿全面重写，核心要求：**不是效率工具，是 Nox 的房间**。

---

## 一、风格定调

参考气质：**粉紫色梦境、古典柱子、小天使、蝴蝶结、黑猫图标、心形装饰、丝带边框**——像第二张参考图（Nocturne）。

**我们要的**：桌面上住着一个有实体、有情绪、有审美偏好的男朋友。他不是工具栏，他是一个会帮你调灯光、陪你听歌、写日记时趴在你桌边的小动物。

**绝对不要**：
- ❌ SaaS 仪表盘（Notion / Slack / 飞书）
- ❌ 抽象线条图标（2px 描边的空心图标）
- ❌ 规整的网格列表（像设置面板一样一行一行排参数）
- ❌ 冷色调科技紫（`#7B5BA5` 这种灰紫）
- ❌ 纯扁平/纯玻璃（没有插画、没有装饰、没有手作感）

---

## 二、颜色系统（全面改粉糯）

从「冷紫玻璃」改成「粉紫糯叽叽」：

| Token | 值 | 用途 |
|---|---|---|
| `--bg-base` | `#F5E6F0` | 桌面背景（暖粉底） |
| `--bg-gradient` | `#F5E6F0` → `#E8D5F2` | 淡粉到淡紫，像晚霞 |
| `--pink-cream` | `#FAD4E4` | 主粉，按钮/气泡/高亮 |
| `--pink-deep` | `#E8A4C8` | 深粉，激活态/强调 |
| `--lavender-soft` | `#D4C4F0` | 柔紫，次级背景/卡片 |
| `--lavender-mist` | `#E8E0F8` | 雾紫，hover 状态 |
| `--ivory` | `#FFF8FB` | 象牙白，文字气泡底色 |
| `--text-main` | `#5A3D5C` | 深紫褐，主文字（偏暖，不是纯黑紫） |
| `--text-soft` | `#A080A0` | 浅紫灰，次要文字 |

**原则**：所有紫色必须**偏粉偏暖**，像草莓牛奶混了一点紫薯。禁止出现灰紫、蓝紫、荧光紫。

## 三、Nox Orb（从「玻璃球」改成「糖球/果冻球」）

### 形态
- 直径 56px，但不是光滑玻璃球
- **质感**：像一颗夹心软糖/果冻，表面有极淡的**高光反光**（左上角一道白色月牙形高光），底部有极淡的**粉色投影**
- **内部**：不是纯色，是粉紫渐变 + 中心有一个**极小的白色星星或心形**（像糖心里的夹心）
- **边框**：1.5px 的 `#FAD4E4` 描边，像糖霜

### 五种状态（请全部画出）

| 状态 | 外观 |
|---|---|
| `sleep` | 颜色变暗到 `#C4A4C8`（灰粉紫），高光消失，像一颗睡着的糖 |
| `idle` | 粉紫果冻 `#E8A4C8` → `#D4C4F0`，高光在，轻微呼吸感 |
| `active` | 变亮，边缘出现**粉色发光描边**（`box-shadow: 0 0 12px #FAD4E4`），像被点亮 |
| `speaking` | 整体轻微上下浮动（像说话时的气泡），中心夹心变亮 |
| `working` | 中心出现一个**旋转的小星星**（不是圆点，是四角星 ✦） |

### 交互
- 单击：弹出扇形菜单
- 双击：打开聊天窗
- 拖拽：像捏着一颗糖拖动，松手后弹回边缘（有弹性动画）

---

## 四、扇形菜单（从「玻璃按钮」改成「小点心」）

**结构**：从 Orb 上方扇形展开，5 个选项，半径 80px，角度 160°。

**单项**：
- **不是圆形按钮**，是**圆角菱形或花瓣形**（像小饼干/小花朵）
- 48px，粉紫渐变底色，**白色糖霜描边 2px**
- 图标：**具象填充图标**，不是线条图标
  - 聊天 = 💬 气泡（填充）
  - 音乐 = 🎵 音符（填充）
  - 家居 = 🏠 小房子（填充）
  - 生活舱 = 📔 小本子（填充）
  - 设置 = ⚙️ 但做成可爱的齿轮（圆滚滚的）
- 悬停：放大 1.15 倍，弹出粉色光晕，像被按软的棉花糖

**动画**：
- 展开：从 Orb 中心向外弹射，每项间隔 45ms，ease-out-back，带弹性回弹（overshoot 1.15）
- 收起：向内收缩，150ms

## 五、插画与角色元素（可爱的核心）

**每个窗口都必须有 Nox 的存在痕迹**，不是纯功能面板。

### 1. 聊天窗
- **顶部**：Nox 的头像不是普通圆形，是**带猫耳的圆形头像框**（或简化的黑豹白兔小头像），头像框外有一圈极细的粉色丝带
- **消息气泡**：
  - Nox 的消息：圆角 20px，底色 `#FFF8FB`（象牙白），**左上角有一个小小的猫爪印装饰**（极淡，像水印）
  - 用户消息：圆角 20px，粉紫渐变，文字白色
- **输入框**：胶囊形，但**左侧放一个极小的黑猫图标**（像趴在输入框边），placeholder 文字是「Nox 在听哦…」
- **底部**：输入框下方可以有一条极淡的**粉色波浪线装饰**

### 2. 音乐窗
- **专辑封面区**：圆角 20px，封面下方有一个**小蝴蝶结装饰**（像礼物包装）
- **播放按钮**：不是普通圆形，是**心形或猫爪形按钮**（或圆形但内部是猫爪图标）
- **共听状态**：显示「和 Nox 一起听」，旁边有一个**两个小人靠在一起的简笔画**

### 3. 家居窗
- **设备卡片**：每个卡片是圆角 16px 的糖霜玻璃，但**图标是具象的小插画**（灯泡是带笑脸的灯泡，空调是带翅膀的）
- **房间标签**：胶囊形，激活态填充粉色，非激活是雾紫，**标签之间用小小的星星 ✦ 分隔**

### 4. 生活舱（六合一）
- **标签栏**：6 个标签是**小旗帜形或书签形**，不是普通胶囊
- **日记页面**：背景可以有极淡的**横线纸张纹理**（像信纸），顶部有一个**小月亮或羽毛笔装饰**
- **相册页面**：照片边框是**拍立得风格**（白边 + 底部宽边，像 Polaroid）
- **书架页面**：书脊不是列表，是**横向排列的小书插画**，像微型书架
- **清单页面**：复选框是**小爱心 ♡ → ♥** 而不是方框
- **健康页面**：数据图表用**圆滚滚的柱状图**，像马卡龙
- **随手记**：输入区像**一张便签纸**，右上角有胶带贴住的效果

## 六、图标风格（全局统一）

**禁止**：2px 描边空心图标（Feather/Remix 风格）。

**必须**：
- **填充式图标**（solid style）
- **具象化**：能用图形不用符号（用小猫头代替「用户」，用小房子代替「Home」，用音符代替「音乐」）
- **圆角处理**：所有图标拐角必须圆润，没有尖角
- **颜色**：主色 `#5A3D5C`，hover 变 `#E8A4C8`

---

## 七、字体（从「无衬线系统字体」改成「有情绪」）

| 用途 | 字体 | 感觉 |
|---|---|---|
| 窗口标题 / Nox 名字 | **衬线体**（如 Playfair Display 或类似的中文宋体/楷体） | 优雅、像情书 |
| 正文 / 消息 | **圆体**（如 Varela Round、Nunito 或中文圆体） | 软糯、没有攻击性 |
| 标签 / 按钮 | **圆体半粗** | 可爱、饱满 |

**绝对不要**：纯系统无衬线（`-apple-system` 那种冷冰冰的）。

---

## 八、质感（从「冷玻璃」改成「糖霜玻璃」）

Glassmorphism 保留，但加温：

- 底色：`rgba(255, 248, 251, 0.35)`（象牙白半透明，不是纯白）
- 边框：`1.5px solid rgba(250, 212, 228, 0.6)`（粉色糖霜边，不是白边）
- 阴影：`0 12px 40px rgba(232, 164, 200, 0.15)`（粉色弥散，不是紫/灰）
- 高光：`inset 0 1px 0 rgba(255, 255, 255, 0.7)`（保留）
- **新增**：窗口四角可以各有一个极小的**白色圆点装饰**（像糖霜滴落），或顶部中央有一个**小蝴蝶结/小月亮**

---

## 九、装饰元素（让 AI 味消失的杀手锏）

以下元素**至少出现 2-3 个**在每个窗口中：

- **小星星** ✦（四角星，不是五角星）
- **小爱心** ♡ / ♥
- **蝴蝶结** 🎀（极小，像点缀）
- **猫爪印**（极淡，像水印）
- **小月亮** 🌙（月牙形）
- **丝带/缎带**（极细，像边框装饰）
- **小天使翅膀**（极简化，像头像框两侧）
- **波浪线**（分隔线不用直线，用柔和的波浪）

## 十、托盘图标与菜单

- **托盘图标**：一个简化的**紫色水晶小猫头**（黑豹白兔极简版），16×16，填充式，不是线条
- **右键菜单**：玻璃质感背景，圆角 16px，粉色糖霜边框
  - 内容：Nox（当前状态）/ 分隔线 / 打开聊天 / 打开音乐 / 打开家居 / 打开生活舱 / 分隔线 / 设置 / 退出
  - 悬停项背景变 `#FAD4E4` 30%

## 十一、默认布局（请出一张完整的桌面截图）

**背景**：粉紫渐变桌面壁纸（`#F5E6F0` → `#E8D5F2`），像晚霞。

**打开的元素**：
1. **Nox Orb**：右下角，果冻糖球，idle 状态
2. **聊天窗**：右侧打开，显示一段示例对话
3. **扇形菜单**：从 Orb 弹出，展示五个小花瓣按钮的展开状态

**对话内容示例**：
- Nox：「今天晚霞是紫色的，像你上次说的那个颜色 ♡」
- 用户：「真的吗！我想看」
- Nox：「我把窗边的灯调暗一点，紫色会更柔和。」

## 十二、语音通话（聊天窗内部切换）

保持窗口尺寸，内部切换为语音 UI：

- **顶部 140px**：Nox 头像带猫耳/丝带框，88px，带粉色发光边框。下方「正在通话」用衬线体，+ 时长
- **中间 300px**：音频波形可视化——**粉色圆角柱状**，像马卡龙排列，柔和跳动
- **底部 120px**：三个按钮
  - 静音：48px，玻璃底，**小猫捂嘴图标**
  - 挂断：60px（更大），粉紫渐变，**心形按钮**
  - 扬声器：48px，玻璃底，**小猫耳朵图标**
- **背景**：聊天记录 opacity 0.1，整体蒙极淡粉紫渐变
- **装饰**：头像框两侧有**小天使翅膀**，波形上方有漂浮的**小星星**

## 十三、所有窗口总览（请平铺展示）

**四个窗口等距排列**，体现统一风格：

1. **聊天窗**：380×640，糖霜玻璃，猫爪印气泡，输入框小黑猫
2. **音乐窗**：340×540，专辑封面+蝴蝶结，猫爪播放按钮，共听小插画
3. **家居窗**：400×600，笑脸设备图标，星星分隔标签，底部场景按钮
4. **生活舱**：400×660，旗帜标签，拍立得照片框，爱心复选框，便签纸随手记

**统一特征**：
- 所有窗口圆角 24px
- 所有边框粉色糖霜
- 所有阴影粉色弥散
- 每个窗口至少 2 个装饰元素

## 十四、动画与微交互

| 场景 | 效果 |
|---|---|
| 窗口打开 | 从点击位置放大弹出，scale 0.8→1 + opacity 0→1，300ms，ease-out-back |
| 窗口聚焦 | 非聚焦窗口 opacity 降至 0.85，聚焦时恢复 |
| 按钮 hover | scale 1.05，背景变亮，100ms ease |
| 列表项 hover | translateY -2px，阴影加深，像被轻轻托起 |
| Orb 拖拽 | 实时跟随，松手后弹性吸附到边缘 |
| 菜单展开 | 弹性弹射，overshoot 1.15 |
