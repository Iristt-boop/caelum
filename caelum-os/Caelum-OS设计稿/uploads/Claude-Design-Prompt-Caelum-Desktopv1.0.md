# Caelum OS 桌面端 —— 设计稿需求文档（可爱版 v3 · 单窗口架构）

> 给 Claude Design 的完整 prompt。核心要求：**不是五个独立 App，是一个完整的 OS。单窗口，左侧 Tab 导航，主内容区切页面。**

---

## 一、风格定调

**Caelum OS** 是一个 AI 伴侣操作系统。桌面端是 Nox 的房间。

参考气质：**粉紫色梦境、古典柱子、小天使、蝴蝶结、黑猫图标、心形装饰、丝带边框**——像 Nocturne 参考图。

**我们要的**：桌面上有一个完整的「房间」，左侧是门框（Tab 栏），右边是房间内的不同区域（页面）。Nox 不是飘在角落的球，而是住在这个房间里，每个页面都有他的痕迹。

**绝对不要**：
- ❌ SaaS 仪表盘（Notion / Slack / 飞书）
- ❌ 抽象线条图标（2px 描边的空心图标）
- ❌ 规整的网格列表（像设置面板一样一行一行排参数）
- ❌ 冷色调科技紫（`#7B5BA5` 这种灰紫）
- ❌ 纯扁平/纯玻璃（没有插画、没有装饰、没有手作感）
- ❌ 多个独立浮动窗（这是单窗口架构）

---

## 二、全局架构（单窗口 + 左侧 Tab）

```
┌─────────────────────────────────────────────────────────┐
│  ▓▓ │                                                   │
│  N  │              主内容区（页面切换）                    │
│  o  │                                                   │
│  x  │   ┌─────────────────────────────────────────┐     │
│     │   │                                         │     │
│  💬 │   │         当前页面内容                     │     │
│  🎵 │   │                                         │     │
│  ⚙️ │   │                                         │     │
│     │   └─────────────────────────────────────────┘     │
│  ⚫ │                                                   │
└─────────────────────────────────────────────────────────┘
   ↑
左侧 Tab 栏（常驻，可折叠）
```

**窗口外壳**：
- 整体是一个圆角 24px 的大窗口（像一张大卡片），无边框阴影，直接贴在桌面上
- 尺寸：默认 1200×760px，可调整大小
- 背景：`#F5E6F0` → `#E8D5F2` 渐变（淡粉到淡紫，像晚霞）

## 三、颜色系统（粉糯系）

| Token | 值 | 用途 |
|---|---|---|
| `--bg-base` | `#F5E6F0` | 桌面/窗口底层背景（暖粉底） |
| `--bg-gradient` | `#F5E6F0` → `#E8D5F2` | 淡粉到淡紫渐变 |
| `--pink-cream` | `#FAD4E4` | 主粉，按钮/气泡/高亮/激活态 |
| `--pink-deep` | `#E8A4C8` | 深粉，强调/选中/图标激活 |
| `--lavender-soft` | `#D4C4F0` | 柔紫，次级背景/卡片 |
| `--lavender-mist` | `#E8E0F8` | 雾紫，hover 状态 |
| `--ivory` | `#FFF8FB` | 象牙白，文字气泡/输入框底色 |
| `--text-main` | `#5A3D5C` | 深紫褐，主文字（偏暖） |
| `--text-soft` | `#A080A0` | 浅紫灰，次要文字 |
| `--glass-bg` | `rgba(255, 248, 251, 0.40)` | 糖霜玻璃底色 |
| `--glass-border` | `rgba(250, 212, 228, 0.60)` | 粉色糖霜边框 |
| `--glass-shadow` | `rgba(232, 164, 200, 0.15)` | 粉色弥散阴影 |

**原则**：所有紫色必须偏粉偏暖，像草莓牛奶混了一点紫薯。禁止灰紫、蓝紫、荧光紫。

## 四、左侧 Tab 栏（最重要的导航骨架）

### 形态
- **宽 72px**，高 100%，贴左侧
- **圆角**：右侧圆角 24px，左侧直角（贴边）
- **质感**：糖霜玻璃——`rgba(255,248,251,0.35)` 底 + `backdrop-filter: blur(40px)` + 右侧 1.5px 粉色糖霜边框
- **阴影**：`inset -2px 0 8px rgba(232,164,200,0.1)`（右侧内发光，像从主内容区透出来的光）

### 结构（从上到下）

| 位置 | 内容 | 说明 |
|---|---|---|
| **顶部 80px** | Nox 头像 | 56px 圆形，带猫耳的头像框，外圈粉色丝带。点击回到 Home 页 |
| **间距 16px** | — | — |
| **中部** | 四个 Tab 图标 | 纵向排列，间距 12px，每个 48px |
| **弹性间距** | — | 自动填充 |
| **底部 80px** | Orb 缩小版 + 设置 | Orb 32px（显示当前状态），下方设置齿轮 28px |

### Tab 图标（填充具象，圆角处理）

| 图标 | 名称 | 具象图形 |
|---|---|---|
| 🏠 | Home | 填充小房子，屋顶有猫耳朵 |
| 💬 | Chat | 填充对话气泡，里面有小猫脸 |
| 🎵 | Music | 填充音符，音符尾巴是猫尾巴形状 |
| ⚙️ | Settings | 填充齿轮，圆滚滚的，中心是小爱心 |

**激活态**：
- 图标底色变成 `#FAD4E4`（主粉），图标本身变白
- 图标右侧出现一条 3px 的粉色竖线（像书签标签）
- 整体有轻微放大 scale(1.08)

**Hover**：
- 图标放大 1.05 倍
- 右侧浮现文字标签（如「Chat」），圆角 8px 糖霜玻璃背景，12px 圆体字

### 可折叠
- 默认展开 72px
- 点击底部「折叠」按钮（或快捷键）→ 收缩到 24px，只显示图标中心一条线
- Hover 折叠状态 → 临时展开到 72px

### 装饰
- Tab 栏顶部和底部各有一个**极小的蝴蝶结**装饰（像挂在门框上）
- 图标之间用**小星星 ✦** 分隔（不是直线）

---

## 五、页面切换动画

- **切换页面**：主内容区整体向切换方向滑动（左出右进或右出左进），300ms，ease-out
- **不是生硬跳转**，是「翻页」感，像翻一本粉紫色的书
- 页面切换时，左侧 Tab 的激活指示器（粉色竖线）有**弹性动画**（overshoot 1.2）

## 六、页面 1：Home（首页 / 仪表盘）

**核心概念**：Nox 的房间入口，一块一块的 widget 拼成的墙面。

### 布局
- **顶部栏**：高 56px

  - 右侧：日期时间（圆体，14px，`#A080A0`）+ 天气小图标（🌤）
  - 底部一条**波浪线分隔**（不是直线）
- **主区域**：可拖拽的 widget 网格，背景是淡粉紫渐变

### Widget 系统（可拖拽 / 可配置 / 大小不同）

**三种尺寸**（像 iOS 小组件）：
- **小（S）**：160×160px，1×1 网格
- **中（M）**：340×160px，2×1 网格
- **大（L）**：340×340px，2×2 网格

**网格系统**：
- 列宽 170px（含 10px 间距），行高 170px（含 10px 间距）
- 页面默认 4 列 × 3 行，可滚动
- 拖拽时 widget 有**弹性晃动**动画，像果冻

### Widget 卡片统一规格
- 圆角 20px
- 糖霜玻璃质感：`rgba(255,248,251,0.35)` 底 + blur + 粉色糖霜边框
- 阴影：`0 8px 24px rgba(232,164,200,0.12)`
- 每个卡片**至少一个装饰元素**（猫爪印水印、小星星角标、蝴蝶结挂饰）
- Hover：translateY -3px，阴影加深，像被轻轻托起

## 十、全局装饰元素（每个页面都必须有）

以下元素**至少出现 2-3 个**在每个页面中：

- **小星星** ✦（四角星，不是五角星）—— 角标、分隔、背景点缀
- **小爱心** ♡ / ♥ —— 复选框、按钮、状态指示
- **蝴蝶结** 🎀 —— 卡片顶部、头像框、封面下方
- **猫爪印** —— 极淡水印、气泡角标、背景纹理
- **小月亮** 🌙 —— 夜间模式指示、天气 widget、顶部栏
- **丝带/缎带** —— 极细边框装饰、头像框外圈
- **小天使翅膀** —— 头像框两侧、Nox 名字旁边
- **波浪线** —— 分隔线（不用直线）

---

## 十一、图标风格（全局统一）

**禁止**：2px 描边空心图标（Feather/Remix 风格）。

**必须**：
- **填充式图标**（solid style）
- **具象化**：能用图形不用符号（用小猫头代替「用户」，用小房子代替「Home」，用音符代替「音乐」）
- **圆角处理**：所有图标拐角必须圆润，没有尖角
- **颜色**：默认 `#5A3D5C`，激活态 `#E8A4C8`，hover 变 `#FAD4E4`

---

## 十二、字体

| 用途 | 字体 | 感觉 |
|---|---|---|
| 窗口标题 / 页面标题 / Nox 名字 | **衬线体**（如 Playfair Display 或中文宋体/楷体） | 优雅、像情书 |
| 正文 / 消息 / 列表 | **圆体**（如 Varela Round、Nunito 或中文圆体） | 软糯、没有攻击性 |
| 标签 / 按钮 / 辅助文字 | **圆体半粗** | 可爱、饱满 |
| 代码 / 终端 | **等宽圆体**（如 JetBrains Mono 或 Fira Code，但用圆润风格） | 技术但不冰冷 |

---

## 十三、质感（糖霜玻璃）

- 底色：`rgba(255, 248, 251, 0.35)`（象牙白半透明）
- 边框：`1.5px solid rgba(250, 212, 228, 0.6)`（粉色糖霜边）
- 阴影：`0 12px 40px rgba(232, 164, 200, 0.15)`（粉色弥散）
- 高光：`inset 0 1px 0 rgba(255, 255, 255, 0.7)`（玻璃顶光）
- **新增**：卡片四角可以各有一个极小的白色圆点装饰（像糖霜滴落）

## 十四、动画与微交互

| 场景 | 效果 |
|---|---|
| 页面切换 | 主内容区整体滑动（左出右进），300ms，ease-out，像翻书 |
| Tab 激活指示器 | 弹性动画，overshoot 1.2，像书签弹出来 |
| Widget 拖拽 | 卡片晃动 + 弹性跟随鼠标，松手后 gentle 落位 |
| 按钮 hover | scale 1.05，背景变亮，100ms ease |
| 卡片 hover | translateY -3px，阴影加深，像被轻轻托起 |
| 输入框 focus | 边框变 `#FAD4E4`，内发光 `0 0 0 3px rgba(250,212,228,0.3)` |
| 开关切换 | 猫爪滑块弹性滑动，200ms ease-out-back |
| 代码块展开 | 高度从 0 弹性展开，代码行逐行淡入 |
| 终端打字 | 字符逐个出现，像 Nox 在实时输入 |

## 十五、输出要求（4 张设计稿）

### 稿 1：Home 页面
- 完整窗口（1200×760），左侧 Tab 栏展开
- Home 页面激活，显示 7 个 widget（天气 M、To Do M、Nox 的话 L、音乐 S、快捷入口 S、健康 M、最近会话 M）
- 展示拖拽状态（一个 widget 正在被拖动，其他 widget 有弹性晃动）
- **必须有**：猫爪印水印、波浪线分隔、小星星角标、蝴蝶结装饰

### 稿 2：Chat 页面（Nox 工作台）
- 三栏布局完整展示
- 左侧会话列表（4 个会话，第二个「API 修复」激活）
- 中间工作区显示一段对话：
  - Nox 说「我在看了」，下方附一个代码块（粉紫主题）
  - 用户说「改这里」
  - Nox 回复「好，我改好了」，下方附浏览器预览卡片（显示网页截图）
- 右侧工具抽屉展开，显示文件树
- **必须有**：代码块的猫爪复制按钮、终端的小猫头提示符、输入框的小黑猫

### 稿 3：Music 页面
- 大专辑封面 + 猫爪播放按钮 + 共听状态
- 播放列表展开（3 首歌）
- **必须有**：封面下方蝴蝶结、进度条猫爪滑块、共听小人插画

### 稿 4：Settings 页面（MCP 插件）
- 左侧分类列表（MCP 插件激活）
- 右侧显示 6 个插件卡片（如 Ombre Brain、HA、健康、网易云、文件、搜索）
- 每个卡片显示图标、名称、状态开关（猫爪滑块）、版本号
- **必须有**：猫爪开关、卡片猫爪印水印、分类列表顶部齿轮+蝴蝶结

- [ ] 颜色是粉糯的，还是冷灰的？

- [ ] 窗口像「房间」还是像「面板」？
- [ ] Chat 页面像「工作台」还是像「聊天软件」？
